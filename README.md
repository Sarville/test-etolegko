# download_bench.py

Простой бенчмарк скачивания по HTTP(S).

## Что делает

- принимает URL (например, ссылку на тяжёлую картинку);
- делает к нему **10 запросов последовательно**, дожидаясь полного ответа на каждый;
- считает среднее время одного запроса и общий объём скачанных данных;
- печатает в консоль скорость скачивания.

## Запуск

```bash
pip install requests
python download_bench.py https://example.com/big-image.jpg
```

## Единицы измерения

| Показатель        | Единица                       |
|-------------------|-------------------------------|
| Среднее время     | секунды (с)                   |
| Объём данных      | МБ (1 МБ = 1024 КБ = 2^20 байт) |
| Скорость скачивания | **МБ/с** (мегабайт в секунду, двоичные МБ) |

Примечание: в скрипте под «КБ» понимаются двоичные килобайты (1024 байта).
